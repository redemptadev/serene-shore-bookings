# 🌊 Coastal Haven

A modern coastal accommodation booking platform designed for discovering and booking beautiful stays along the Kenyan coast.

## ✨ About

Coastal Haven is a full-stack web application that connects travelers with coastal accommodation while giving property hosts and administrators the tools to manage listings, bookings, pricing, payments, and guest communication.

The platform is designed with tourists in mind, providing a simple and seamless experience from discovering a stay to completing a booking.

## 🚀 Features

- 🏝️ Browse coastal accommodation
- 🔎 Search and explore available stays
- 📅 Check availability and make bookings
- 💳 Secure payment integration
- 📧 Booking confirmation emails
- 📱 Phone number authentication with country codes
- 🔐 Google authentication
- ⭐ Guest ratings and reviews
- 💬 Guest remarks and feedback
- 👤 Guest profiles
- 🏠 Host property management
- 💰 Dynamic pricing management
- 📊 Admin dashboard
- 📩 Email and notification management
- 📱 WhatsApp contact integration
- 📸 Social media and contact information management
- 🌴 Coastal-themed user interface

## 👥 User Roles

### Guests
Guests can:
- Create an account or sign in
- Browse available properties
- View property details and prices
- Check availability
- Make bookings
- Complete payments
- Receive booking confirmations
- Leave ratings, reviews, and remarks

### Hosts
Hosts can:
- Add and manage their properties
- Update property information
- Manage availability
- Adjust pricing
- View bookings
- Manage guest information
- Add contact and social media details

### Administrators
Administrators can manage the entire platform, including:
- Properties
- Hosts
- Users
- Bookings
- Prices
- Payments
- Reviews
- Contact information
- Notifications
- Platform settings

## 🛠️ Tech Stack

- **Frontend:** React + TypeScript
- **Build Tool:** Vite
- **Styling:** CSS
- **Backend & Database:** Supabase
- **Authentication:** Supabase Auth
- **Deployment:** Vercel
- **Version Control:** GitHub

## 🌍 Purpose

Coastal Haven aims to provide a reliable and user-friendly digital platform for discovering and booking accommodation along the Kenyan coast while giving hosts full control over their properties and bookings.

## 📍 Location

Kenyan Coast — Kilifi and surrounding coastal destinations.
